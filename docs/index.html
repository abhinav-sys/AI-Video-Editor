AI Video Editor

Bulk-edit videos with natural language. Replace banner dates, swap logos, and render with FFmpeg — FastAPI backend + Next.js UI.

View on GitHub Run locally

What it does

Prompt → edits

Turn “replace 15 & 16 august to 26 & 27 september” into structured edit instructions.

In-banner replace

Detects the date line inside lower-third banners and redraws text in place.

Bulk jobs

Queue multiple clips, track progress, download a ZIP of edited outputs.

Local stack

backend  →  FastAPI :8000
frontend →  Next.js :3000
render   →  FFmpeg + Pillow banner detection

GitHub Pages hosts this project site only. The full editor (upload + FFmpeg render) needs to run locally or on a server — see the README quick start.
